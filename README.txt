사진 커서 (PhotoCursor) 사용법

[켜기]
PhotoCursor.exe 더블클릭

[끄기]
Ctrl + Alt + Q
또는 PhotoCursor.exe 를 한 번 더 실행하고 "예"

[내 사진 넣기] 이 폴더에 아래 이름으로 넣으세요. 투명 배경 PNG가 가장 자연스러워요.
  normal.png : 평소 (화살표 커서 자리)
  click.png  : 클릭하는 순간 (어디서 클릭하든)
  text.png   : 글자 입력칸 위 (I자 커서 자리). 없으면 Windows 원래 커서
  link.png   : 링크·버튼 위 (손가락 커서 자리). 없으면 Windows 원래 커서

[설정 바꾸기]
settings.txt 를 메모장으로 열어 '=' 오른쪽 값만 바꾸고 저장 → 끄고 다시 켜기.
각 설정 설명은 settings.txt 안에 있어요.

[처음 실행할 때 파란 경고창("Windows의 PC 보호")이 뜨면]
코드 서명(유료)이 없는 프로그램이라 뜨는 창이에요. "추가 정보" → "실행" 을 누르세요.

[원래 커서로 안 돌아올 때]
PhotoCursor.exe 를 다시 켰다가 Ctrl + Alt + Q, 또는 컴퓨터 다시 시작.

[컴퓨터 켤 때 자동으로 켜기]
Win + R → shell:startup → 열린 폴더에 PhotoCursor.exe 의 "바로 가기"를 넣기
(exe 자체를 옮기면 사진과 설정 파일을 못 찾아요)
